# 行政工作表樣板

狀態：已整理為可複製的行政填寫樣板；已有獨立清票與第二輪抽選核心，尚未串接完整抽籤前端、CSV或試算表產生工具。

遠端：[機腳踏車位抽選工作表（樣板）](https://docs.google.com/spreadsheets/d/1QNEX0ERAbYyOOoFKuz9_oScHIaoW8MPpKMIcA6aXpd4/edit)。位於指定的Google Drive抽籤系統開發資料夾，不自行複製或分享至社區帳號。

## 分頁順序

1. 填寫說明：行政操作及交接說明，整頁限制編輯。
2. A棟資料：戶號與三項參與選單，戶號及名額警示區受保護。
3. B棟資料：同上。
4. 無障礙車位資料：前兩欄固定順位及14／2／3，第三欄選戶號，最後兩欄自動判斷棟別及撥補；除戶號外皆受保護。
5. 第一輪繳費狀態：A棟在上B棟在下，棟別與戶號受保護及凍結，三項入帳核取方塊可編輯。

已刪除過時且未填資料的「前置登記」，以及行政人員不需維護的「車位主檔」，不留隱藏分頁。車位候選編號及配置規則以本repo文件為來源，後續程式依規則產生抽籤池。既有參與選擇、無障礙登記與入帳紀錄未重設。

## 年度使用與交接

最新分工：第一輪樣板預定名稱為「第一輪機腳踏車位抽選工作表（樣板）」，第一輪繳費狀態留在本工作表；清票後另產生第二輪工作表，詳見[活動階段與CSV產出](activity-states.md)。此處記錄命名方向，遠端實際名稱仍以連結目標為準。本次活動日期見[116年度抽選時程](../planning/schedule-116.md)。

- 使用者預計自行複製後放到社區Google Drive，年度檔名例如「116年度機腳踏車位抽選工作表」。本檔保持不綁年度的樣板名稱。
- 建議使用Google Sheets的建立副本，保留原樣板；若下載再上傳，需重查選單、核取方塊、公式、格式及保護權限。
- 保護是限制編輯，不只是警告；擁有者仍可修改。副本權限可能隨複製及上傳方式改變，交付後需以一般編輯者帳號檢查。
- 本次未改分享權限、未建立116年度正式副本，也未操作社區正式登記。

## 行政說明內容

已在最前分頁說明填寫順序、可編輯範圍、機車一輪／兩輪意願、腳踏車大小名額及超額回報、無障礙順位與撥補、入帳勾選、截止後依實際配位清查、異動及交接方式。說明頁不放開發路徑、原始代碼或內部實作細節。

最新腳踏車規則：大小皆使用不參與／一輪／兩輪下拉選單，預設不參與。無論登記是否超額，第一輪剩餘及未繳釋出都可進第二輪；各類無第二輪參與戶時跳過。樣板及測試副本已同步遷移舊值，原參與轉為一輪，未替住戶推定第二輪意願。

樣板不是自動抽籤系統；不會自動抽選、產生繳費單、執行清票、同步正式配位或啟動第二輪。下一階段程式需按戶號讀取四張操作表，不能依檔名固定年度或假定被移除的車位主檔仍存在。
