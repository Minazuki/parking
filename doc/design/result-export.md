# 結果CSV下載

狀態：已實作每輪結果的前端下載第一版。CSV由本機Go已驗證的JSON斷點產生，不改寫核心存檔，不自動上傳Drive。繳費工作表與其他行政報表格式仍待後續處理。

第一輪讀activity、0、1、2；第二輪讀activity、0、5、6。只有使用者明確按「下載第一輪／第二輪結果 CSV」才建立Blob與Chrome下載，演出完成不自動下載。

| 欄位 | 內容 |
| --- | --- |
| 年度 | 已保存的民國活動年度 |
| 活動ID | activity.json的activityId |
| 輪次 | 1或2 |
| 車種類型 | 本池名稱；第一輪另含機車無障礙配置 |
| 戶號 | 配位、候補或未配位戶號；空位／略過列留空 |
| 結果 | 配位、優先配置、候補、未配位、空位、略過 |
| 車位號碼 | 實際車位；候補留空 |
| 候補順位 | 候補rank；其他留空 |
| drand round | 該輪已保存的round |
| 結果SHA256 | 配位JSON的JSON.stringify內容以UTF-8雜湊 |
| 備註 | 略過原因代碼；其他留空 |

UTF-8 BOM、CRLF及完整雙引號欄位，雙引號依CSV規則加倍。保持保存的池與配位順序；第二輪只包含第二輪新增結果，不混成清票後的年度最終配置。第一輪包含無障礙優先配置；各池未配位、剩餘空位與略過均保留。

檔名包含年度、輪次、drand round與結果摘要前8碼，例如`116年度第1輪機腳踏車位抽選結果_round33382601_XXXXXXXX.csv`。同份保存結果重做匯出會產生同樣內容及摘要；回退後換seed或結果時可由檔名辨識不同版本。正式核對使用完整結果摘要，不只比較前8碼。

實作：`client/src/models/result-csv.ts`。單元測試確認BOM、CRLF、保存配位與摘要重現；Chrome測試確認完成不下載、點擊後才產生下載，以及下載內容符合保存結果。
