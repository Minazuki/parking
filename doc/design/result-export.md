# 結果CSV下載

狀態：已實作每輪結果下載。CSV由本機Go已驗證的JSON斷點產生，不改寫核心存檔，不自動上傳Drive。

第一輪讀activity、0、1、2；第二輪讀activity、0、5、6。只有使用者明確按「下載第一輪／第二輪結果 CSV」才建立Blob與Chrome下載，演出完成不自動下載。

## 對外欄位

CSV固定只有以下五欄，依此順序：

| 欄位 | 內容 |
| --- | --- |
| 輪次 | 1或2 |
| 車位類型 | 機車位／腳踏車大／腳踏車小；機車不分A／B棟，無障礙亦歸機車位 |
| 戶號 | 抽中、候補或未取得車位的戶號；剩餘空位列留空 |
| 車位 | 實際車位編號；候補或未取得車位留空，腳踏車保留大／小前綴 |
| 候補 | 候補順位數字；其餘留空 |

不輸出年度、活動ID、結果類型、drand round、摘要或備註欄。第一輪包含無障礙優先配置；各池保留未取得車位的住戶與剩餘空位，無住戶的空位列以車位欄辨識。略過原因只保留JSON及畫面，不另加空白CSV列。

UTF-8 BOM、CRLF及完整雙引號欄位，雙引號依CSV規則加倍。保持保存的池與抽出順序；第二輪只包含第二輪新增結果，不混成清票後的年度最終配置。

## 檔名與查驗

檔名仍包含年度、輪次、drand round與結果摘要前8碼，例如`116年度第1輪機腳踏車位抽選結果_round33382601_XXXXXXXX.csv`。摘要為配位JSON的JSON.stringify內容以UTF-8計算SHA-256；同份保存結果重做匯出會產生同樣內容及摘要。完整seed證據與配位JSON留在年度workspace，不為了縮減CSV而刪除。

實作：`client/src/models/result-csv.ts`。單元測試確認五欄、類型合併、候補、無障礙、BOM、CRLF與摘要重現；Chrome測試確認點擊後才下載，且內容符合保存結果。

## 清票Markdown報表

清票結果頁可手動下載`<年度>年度清票報表.md`。資料只取activity與已保存4/清票結果，下載不讀原始CSV、不重算或修改存檔，也不取得seed。

報表包含：

- 可供第二輪抽選的車位：車格類型、號碼、釋出原因。`vacantSpaces`標示「未抽出」，`released`標示「未繳費釋出」。
- 第二輪登記與車位池摘要：每類參與戶數、實際車位數、候補項目數。
- 各類完整參與戶號、實際車位清單及候補項目。

類型統一顯示機車位／腳踏車大／腳踏車小，不分A／B棟。空名單明確標示「無」。實作為`client/src/models/review-report.ts`，內容以UTF-8 Markdown下載，可手動上傳Drive留存。
