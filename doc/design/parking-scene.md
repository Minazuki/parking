# 停車場3D基本場景

狀態：2026-10-26使用者確認B1機車及1F腳踏車模型定案，作為後續展示的配置基準。已使用TresJS／Three.js建立基本場景，支援俯視／斜俯視、旋轉、平移、縮放、定位高亮、分類顯示及無障礙拆分預覽。此版本不套用活動配位；另有虛構住戶進場預覽，可整批播放或依戶號查詢。

## MVVM與資料

```mermaid
flowchart LR
    layout["layouts.json<br/>原圖編號與相對位置"] --> model["layout.ts<br/>公尺尺寸與車格生成"]
    model --> vm["useParkingScene<br/>區域、篩選、選取與視角"]
    vm --> view["ParkingView<br/>Vue操作與資訊"]
    view --> scene["TresJS場景<br/>幾何、文字、鏡頭與高亮"]
```

不需要安裝Blender或其他建模軟體：車格與隔間由程式生成，使用Chrome即可查看。將來若加入精細外部模型，可另外匯入glTF／GLB素材。

3D頁面以動態import載入，工作台不會預先載入3D引擎。場景使用正交攝影機及on-demand渲染；文字由本機Canvas字圖集產生，不依賴外部模型或字型下載。

靜態位置及尺寸與抽選結果分開。未來動畫可把Go保存的spaceId對應到模型位置，但場景不請求seed、不執行算法、不改變0至6斷點。此版本是獨立模型預覽，甚至不需要Go服務即可查看。

## 啟動與操作

```sh
npm run dev:client
```

Chrome開啟http://127.0.0.1:5173/?view=parking，或從2D工作台右上方「停車場3D」進入。

- 切換B1機車／1F腳踏車。
- 斜俯視時拖曳旋轉、右鍵平移、滾輪縮放；俯視時拖曳平移。
- 點車格或輸入編號定位，側欄顯示車位、所在排與公尺尺寸。
- 全螢幕只展開模型區，重設恢復整體視角。
- 無障礙拆分開關只改預覽；車位清單可作沒有WebGL時的基本核對入口。

## 驗證及後續

測試檢查150／57原始編號完整、指定公尺尺寸、非連續順序、拆分範圍、既有存檔候選spaceId可對應，以及場景選取與篩選。Chrome測試檢查兩區切換、Canvas、定位、俯視及拆分，並確認沒有發出活動API請求。

後續：校正進場支線與演出節奏，再沿用已確認的模型，將活動存檔的無障礙配置套入模型、顯示實際抽選池與既有配位，再接戶號卡片演出。無需為模型重新測量整個停車場。

## 住戶物件進場預覽

2026-10-26建立第一版，右側「住戶進場演出」使用999開頭的虛構戶號；不呼叫活動API、不取得seed、不寫入存檔。可整批進場、重播、直接顯示結果、收起物件，以及依戶號只播放該戶記錄。切換區域會停止原動畫。

機車物件在已裁除地板的左上場外集合，沿上方路線進入圓弧與B棟梯廳間的車道口，再循車道主線與車格支線抵達配位；候補留在左上場外。腳踏車從入口外進場，小車位經大27左側的門口進入；候補留在入口外依順位排列。集合區不補回地板，鏡頭在播放時納入場外範圍。

路線以固定轉折點製作，不在演出時做抽選；位置依路程內插、錯開出發時間，物件到站後車格亮起，並轉成車格方向。預覽最多播放30秒，重播只重設播放時間。使用程式幾何建立小型機車／腳踏車，不下載外部素材；尺寸小於標準車格，避免橫向戶號卡片互相覆蓋。整批播放預設不顯示戶號，點擊物件後頭頂顯示漫畫對話框；同時只開啟一個，另選物件會替換。查詢戶號會自動開啟對話框並跟著物件進場，候補仍留在場外。有配位者在移動中只顯示戶號，抵達後才顯示車位編號，側欄選取資訊同步遵循此規則；候補仍顯示候補順位。對話框以細連線連到物件，不使用三角尾巴，以免遮住模型。對話框與文字整體放大為初版的150%；靠近畫面上緣時改在物件下方顯示，避免文字被裁切。對話框使用Three.js Sprite始終朝向鏡頭，依正交攝影機縮放維持可讀的畫面大小；可手動關閉。側欄清單亦可選取物件。動線與視覺節奏可繼續調整。正式存檔接入、年度戶號查詢匯出與完整梯次資料仍待實作。

邏輯在`models/parking/arrival.ts`，播放與查詢狀態在`viewmodels/useArrivalPreview.ts`，卡片渲染在`scenes/ArrivalCards.vue`。同一配位於整批或單戶查詢時維持相同起點、路線與出發順序。
