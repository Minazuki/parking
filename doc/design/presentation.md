# 前端抽籤演出草案

狀態：展示需求已提出，以下畫面分段與故障恢復方式為提案。

## 使用情境

會議室操作，現場錄影並直播。操作人員按下抽籤按鈕，觀眾需能辨識活動、輪次、參與數量與配位結果。

## 畫面順序

1. 待機：活動名稱、年度、車位類型與輪次。
2. 名單說明：展示本輪不參加戶別與數量；用語區分不使用與逾期未繳。
3. 數量確認：參與戶數、可抽車位數，以及必要的保留或已配置數量。
4. 開始抽籤：操作人員確認後按下按鈕，呈現戶號與車位的隨機演出。
5. 揭曉：逐戶或整批展示配位，節奏待確認。
6. 結果總覽：展示結果，提供報表與正式結果下載。

## 行為設計提案

- 結果產生與動畫播放分離；演出途中不重新抽取結果。
- 在揭曉前保存結果；保存位置、成功判定與故障處理尚待設計，不能只靠下載按鈕保證已落檔。
- 重新整理或畫面中斷後能恢復既有結果，重播時清楚標示。
- 正式抽籤執行中防止重複點擊；重新抽籤的權限與程序另議。
- 使用大字、足夠對比與清楚進度；配合實際投影及直播設備試播。
- 演練與正式活動需有清楚標示，演練使用虛構資料。

## 待確認

一次揭曉幾戶、動畫長度與音效、現場操作與投影是否同螢幕、名單是否分頁、公開顯示戶號的格式、報表版型。
