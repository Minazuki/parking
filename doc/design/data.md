## 戶別定義（2026-10-25 更新）

- 使用者確認依棟分成「A棟資料」與「B棟資料」兩張工作表（原名A棟戶別／B棟戶別）。
- 戶號格式為 `{門牌號碼}-{樓層}`，例如 `151-2`。舊文件的 `151-02F` 正規化為 `151-2`，移除樓層前導零與 F。
- 戶號以文字保存，直接作為前置登記及後續結果的關聯代碼，取代原草稿的獨立戶別代碼與顯示戶號。

| 欄位 | 型別 | 用途 |
| --- | --- | --- |
| 戶號 | 文字 | 全體戶別中唯一，符合上述格式 |
| 機車位 | 文字下拉選單 | 放棄、一輪、兩輪；預設一輪；匯出代碼0／1／2 |
| 腳踏車（大） | 文字下拉選單 | 不參與、一輪、兩輪；預設不參與；匯出代碼0／1／2 |
| 腳踏車（小） | 文字下拉選單 | 不參與、一輪、兩輪；預設不參與；匯出代碼0／1／2 |

兩張資料表目前各有上述四欄，已刪除獨立門牌號碼、樓層、棟別與行政備註。戶號不可跨表重複；門牌與樓層如有需要可由戶號解析，棟別由所在分頁識別。

A棟資料與B棟資料的戶號（A整欄）已設定限制編輯保護，一般編輯者不能修改；擁有者仍可修改。機車位與大／小腳踏車的下拉選單維持可編輯。

機車位「兩輪」表示參與第一輪及第二輪的意願，並非只參與第二輪。依使用者同意，行政表改存文字下拉選項，原「參與類型」欄改名「機車位」。原有數字已逐戶轉為對應文字，保留每戶選擇；預設機車一輪、腳踏車大／小不參與。

機車第一輪採全戶預設參加，並非申請制。行政人員不需逐戶登記「參加第一輪」：不修改者維持一輪，明確放棄者改放棄，願意加抽第二輪者改兩輪；無障礙需求另於專頁按先後登記。放棄戶只減少該棟第一輪參與戶數，不減少其一般抽籤池，實際剩餘車位進第二輪。取得無障礙位的戶別另依配置結果排除一般抽籤，不必改寫原參與意願。腳踏車採不參與／一輪／兩輪，預設不參與，不能套用機車全戶預設參加。

最新規則：腳踏車大小均支援兩輪，不以第一輪登記超額為前提。截止清票後的釋出與第一輪剩餘車位納入該類第二輪；沒有第二輪參與者就跳過。第二輪實際資格仍依後續規則核定。

行政人員使用原生文字下拉選單，儲存值就是文字。系統CSV匯出時明確轉碼：機車位放棄=0、一輪=1、兩輪=2；腳踏車不參與=0、一輪=1、兩輪=2。Google Sheets內建下載CSV會保留文字，不等於已轉碼的系統CSV。未來匯出工具應檢查空白及未知文字並報錯，不能默認轉為0；系統匯入時戶號保留文字，參與代碼解析為整數。

「前置登記」分頁已刪除，參與意願以A／B棟資料為來源，不維護兩份。尚未實作CSV匯出工具。

## 第一輪繳費狀態

依使用者最新要求，分頁命名為「第一輪繳費狀態」，只記錄入帳；不再依參與意願顯示「不適用」。

| 欄位 | 行為 |
| --- | --- |
| 棟別 | A棟在上、B棟在下，受保護欄位 |
| 戶號 | 列出全部戶別，固定文字識別，受保護欄位 |
| 機車位已繳費 | 核取方塊，確認該項入帳後勾選 |
| 腳踏車（大）已繳費 | 核取方塊，確認該項入帳後勾選 |
| 腳踏車（小）已繳費 | 核取方塊，確認該項入帳後勾選 |

全部150戶的三項都提供核取方塊，共450格。初始false（未勾選），true（勾選）代表已確認入帳；既有勾選保留，原本「不適用」改為未勾選。

依使用者要求，第一欄新增棟別，依A棟65戶、B棟85戶的順序排列。棟別及戶號（A:B整欄）設定限制編輯保護，不只是警告；擁有者仍可修改，一般編輯者只能操作未受保護的繳費欄。另凍結前兩欄與表頭，捲動時保留戶別識別。原有戶號與全部繳費值已核對保留。

此頁與參與意願分開：是否參與看A／B棟資料，是否取得車位看實際抽籤結果，是否已入帳看本頁。未勾選本身不表示放棄或欠費；截止後需結合實際配位與繳費核對，再判斷未繳與車位釋出。

第一輪機車位獲配戶截止後核對未繳，視同放棄該車位，原配位釋出進第二輪。保留其第一輪配位及未繳入帳紀錄，另外記錄清票釋出結果，不回頭將原始登記意願改成放棄。

使用固定戶號清單，不因參與意願變動而刪除、隱藏或移動紀錄；新增戶別時依戶號核對補入。登記異動不覆蓋既有入帳紀錄，避免動態名單與手動勾選錯位。

金額、期限、繳費單、第二輪繳費，以及是否所有參與項目均須收費仍待確認。

## 建議資料原則

- 未填答與明確表示不使用分開表示；不把空白直接視為放棄。
- 戶號及車位代碼保留文字格式，避免前導零消失。
- 原始登記意願、審核資格、抽籤結果與繳費狀態分開，避免覆蓋原始資料。
- 機車與腳踏車分別識別輸入與結果，是否共用資格規則另議。
- 無障礙需求不直接視為已核准或保證配置。
- 正式輸入需檢查必填值、重複戶別與車位代碼、無法識別的資料及數量一致性；多車位資格定案後再定義重複判定。
- 公開報表與行政內部資料的欄位分開確認，避免在直播顯示備註或其他不必要資料。
