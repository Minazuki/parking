# 機車位與無障礙配置規則

來源：2026-10-25 使用者說明。下列已確認範圍與待確認情境分開記錄。

## 已確認

- 原機車位編號為1–150，車位號碼一律作為文字識別。
- 2、3、14為無障礙機車位。
- 無障礙車位採登記順序直接分配，不抽籤；車位分配順序為14 → 2 → 3。
- 每個未配置無障礙的原車位均拆成兩格（原號及原號-1），全部加入B棟第一輪一般抽籤池，不刻意保留空號。無人登記時即14及14-1、2及2-1、3及3-1全數加入。
- 已配置的原車位與其-1編號皆不進一般池；是否從A棟撥補另依A棟實際獲配戶數計算，不影響未配置車位拆分後加入B棟第一輪池。
- B棟候選抽籤編號：1–85，加14-1、2-1、3-1。
- A棟候選抽籤編號：86–150。
- 已配置為無障礙使用的實體車位不能同時重複分配為一般車位；拆分格的啟用必須與實體車位配置一致。
- 取得無障礙機車位的戶別排除第一輪一般機車位抽籤，不重複配位。
- A、B棟住戶皆可登記無障礙機車位，依同一登記順序配置。
- 每有1戶A棟住戶實際取得無障礙位，就從A棟一般池撥1格給B棟，依序為86 → 87 → 88。依獲配戶數判斷，不依申請人數或總登記順位判斷。
- B棟住戶取得無障礙位時不撥補。混合登記時只計算其中A棟實際獲配戶數。
- 第一輪一般機車位全戶預設參與，行政只登記放棄及第二輪意願等異動。主動放棄者從該棟參與名單排除，但不刪減車位池，配位後自然多出的未配位車位進第二輪，不因此跨棟撥補。

## A棟撥補B棟

| A棟無障礙獲配戶數 | 撥給B棟的編號 | A棟一般抽籤池 |
| --- | --- | --- |
| 0 | 無 | 86–150，共65格 |
| 1 | 86 | 87–150，共64格 |
| 2 | 86、87 | 88–150，共63格 |
| 3 | 86、87、88 | 89–150，共62格 |

撥補是同一格由A池移至B池，不新增車位，也不能在兩池重複出現。無障礙獲配戶先移出其所屬棟的一般參與名單，再依A棟獲配數執行撥補；第一輪一般機車位登記為放棄的戶別同樣不進一般參與名單。

例如三戶都來自A棟，無障礙配置依序使用14、2、3，這三戶不抽一般機車位，86、87、88撥給B棟；若三戶都來自B棟，則不撥補。未配置的無障礙原位各拆成兩格，一律加入B棟第一輪池。

## 無人登記無障礙的數量核對

| 棟別 | 一般可抽格數 | 目前戶數 | 全戶參與第一輪後的剩餘 |
| --- | --- | --- | --- |
| A | 65 | 65 | 0 |
| B | 88 | 85 | 3 |

全體一般可用153格，是150個原編號加3個拆分編號，不是153個原始實體車位。計算前提是無人登記無障礙、全戶參與第一輪，且沒有其他車位停用或限制。

## 各登記戶數的第一輪處理

| 無障礙獲配戶數 | 無障礙配置原位 | 拆分後加入B棟第一輪的編號 |
| --- | --- | --- |
| 0 | 無 | 14、14-1、2、2-1、3、3-1 |
| 1 | 14 | 2、2-1、3、3-1 |
| 2 | 14、2 | 3、3-1 |
| 3 | 14、2、3 | 無 |

這些拆分格均正常參加第一輪；第一輪隨機配位後實際剩餘的車位，以及期限後未繳釋出的車位，才進第二輪，不指定某幾格必須空出。

數量核對：令k為無障礙實際獲配戶數，a為其中A棟戶數、b為B棟戶數，k=a+b。假設其餘全戶參與且無停用，A棟一般池65-a格對65-a戶；B棟一般池88-2k+a格對85-b戶，剩餘3-k格。例如只有1戶獲配，不論來自哪棟，B棟第一輪均剩2格，但不預先指定剩餘編號。

## 第二輪候補與遞補

第二輪機車A／B合併，與大、小腳踏車各自建立候補順位；共同規則見[活動流程](workflow.md)。

## 無障礙車位資料分頁

已依使用者要求新增「無障礙車位資料」，預留3個配置順位，初始戶號全部留空。

| 欄位 | 操作 |
| --- | --- |
| 登記順位 | 固定1、2、3，受保護 |
| 配置車位 | 第二欄固定文字值14、2、3，不依戶號有無改變，受保護 |
| 戶號 | 第三欄，由A／B棟既有戶號選單選取，依實際登記先後由上往下填 |
| 棟別 | 依戶號自動判斷，受保護 |
| 撥補B棟車位 | A棟獲配依累計A棟戶數顯示86、87、88；B棟顯示不需撥補，受保護 |

行政人員填入已確認可配置的戶別；資格審核及超過3戶的處理仍待定。公式檢查重複戶號與跳順位，異常時棟別或撥補欄顯示需核對；配置車位欄維持固定值，不能僅依該固定值判定已有效獲配。這不是登記時間的自動稽核紀錄，行政人員需維持真實先後順序；確認後如何封存順位仍待定。

此頁只計算配置及撥補提示，不會自動改寫A／B棟參與意願、第一輪繳費、車位主檔或正式抽籤池。後續抽籤工具須讀取本頁，將獲配戶排除一般機車抽籤並調整池子。未配置原位拆分並加入B棟第一輪池的規則已確認，但此表仍只提供配置與撥補提示。
